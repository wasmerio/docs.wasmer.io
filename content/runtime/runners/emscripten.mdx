# Emscripten Runner

<Callout type="warning">
Emscripten support was removed in Wasmer 5.0. The Wasmer runtime no longer
runs packages that use the Emscripten runner.
</Callout>

Packages should target [WASI(X)](/runtime/runners) instead. See
[wasix.org](https://wasix.org) for how to compile your application for WASIX.
