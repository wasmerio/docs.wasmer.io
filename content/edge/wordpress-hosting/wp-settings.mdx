# Customize WordPress settings

You can manage WordPress defines such as `WP_DEBUG=true` from the Wasmer dashboard, without editing `wp-config.php` manually.

## Update WordPress defines

1. Open your app in the [Wasmer dashboard](https://dashboard.wasmer.io).
2. Select **WordPress** in the sidebar.
3. Scroll to **WordPress configuration**.
4. Enter the define in **Constant name** and its value in **Value**.
5. Click **Save constant**.
6. Click **Redeploy to apply configuration**, then confirm.

<ImageLoader img={settingsConfig} alt="WordPress configuration panel on the WordPress tab, with a saved constant and a new one ready to save" />

## Common examples

```text
WP_DEBUG = true
WPDEFINE_WP_DEBUG_LOG = true
WPDEFINE_SCRIPT_DEBUG = true
```

You can enter `WP_DEBUG`, `WP_POST_REVISIONS`, `WP_HOME`, and `WP_SITE` by name. For any other define, add `WPDEFINE_` before its name. For example, enter `WPDEFINE_WP_DEBUG_LOG` to set `WP_DEBUG_LOG`.

Type `true` or `false` for boolean values, and type strings or numbers as they are.

<Callout type="info">
Configuration changes are applied during redeploy, which keeps your WordPress settings consistent across future deployments.
</Callout>
