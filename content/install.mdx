# Install Wasmer

import { Callout, Tab, Tabs } from '@components/nextra-theme';

Run Wasmer as a standalone CLI or embed the Runtime in a JavaScript or Python
application with an SDK.

<Tabs items={['CLI (Bash)', 'CLI (PowerShell)', 'JavaScript SDK', 'Python SDK']}>
  <Tab>
    **Unix** (macOS, Linux):

    ```bash copy
    curl https://get.wasmer.io -sSfL | sh
    ```

    Or, to install a specific version:

    ```bash /7\.3\.0/ copy 
    curl https://get.wasmer.io -sSfL | sh -s "v7.3.0"
    ```

    <Callout type="info">
      Other installation methods are available here:
      https://github.com/wasmerio/wasmer-install
    </Callout>


    ### Is Wasmer up to date?
    Wasmer updates very frequently. If you have installed Wasmer some time ago, chances are your Wasmer version is out of date. Get the latest version of Wasmer by running:

    ```bash copy
    wasmer self-update
    ```


  </Tab>

  <Tab>
    **PowerShell** (Windows):

    ```bash copy
    iwr https://win.wasmer.io -useb | iex
    ```

    Or, to install a specific version:

    ```bash /7\.3\.0/ copy
    $v="v7.3.0"; iwr https://win.wasmer.io -useb | iex
    ```

    <Callout type="info">
      Other installation methods are available here:
      https://github.com/wasmerio/wasmer-install
    </Callout>

    ### Is Wasmer up to date?
    Wasmer updates very frequently. If you have installed Wasmer some time ago, chances are your Wasmer version is out of date. Get the latest version of Wasmer by running:

    ```bash copy
    wasmer self-update
    ```


  </Tab>


  <Tab>
    **npm**:

    ```bash copy
    npm install @wasmer/sdk
    ```

    **pnpm**:

    ```bash copy
    pnpm add @wasmer/sdk
    ```

    Import `@wasmer/sdk/node` in Node.js or `@wasmer/sdk/browser` in a
    browser. Continue with the [JavaScript SDK guide](/runtime/js).
  </Tab>

  <Tab>
    ```bash copy
    python -m pip install wasmer-sdk
    ```

    Continue with the [Python SDK guide](/runtime/python).
  </Tab>

</Tabs>
