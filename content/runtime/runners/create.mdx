# How to create a Runner

Runners define how a Wasmer package or WebAssembly module is executed.

The `wasmer` CLI ships with the [WASI(X)](/runtime/wasix) runner only, and
custom runners cannot be registered with it. If you embed the
[`wasmer-wasix`](https://docs.rs/wasmer-wasix) crate in your own application,
you can implement its `Runner` trait to execute packages in a custom way.

If you are interested in custom runners, please let us know here:

https://github.com/wasmerio/wasmer/discussions/3997
