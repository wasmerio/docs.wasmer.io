# Database Management

Each WordPress app includes a managed MySQL database. WordPress apps always use MySQL; other engines are not available for WordPress. For databases on non-WordPress apps, including PostgreSQL, see the [Databases documentation](/edge/learn/databases).

The simplest way to inspect the database is through the database explorer, which opens Adminer in your browser.

## Open the database in Adminer

1. Open your app in the [Wasmer dashboard](https://dashboard.wasmer.io) and select **Databases** in the sidebar.
2. Click the database name to show its connection details, such as the host, port, username, and password.
3. Click **Open database explorer**. Adminer opens in a new tab.
4. Browse WordPress tables such as `wp_options`, `wp_posts`, `wp_users`, and `wp_terms`.

## When to use it

The database explorer is useful when you need to:

- Inspect WordPress tables directly
- Verify a setting in `wp_options`
- Check whether content, users, or metadata exists
- Troubleshoot a plugin or theme issue that affects stored data

<Callout type="warning">
Editing production data directly in the database can break your site immediately. Make small, targeted changes only when you understand the impact.
</Callout>
