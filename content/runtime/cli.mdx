# `wasmer run` CLI

Run a WebAssembly file or Wasmer container.

<Callout type="info">
  To embed the same packages and WASIX runtime in an application, use the
  [JavaScript SDK](/runtime/js) or
  [Python SDK](/runtime/python).
</Callout>

## Usage

### Run a Wasmer package

All packages published on [Wasmer Registry](/registry) can be run with the `wasmer run` command.

```bash copy
wasmer run python/python
```

Some packages, such as `cowsay`, have multiple commands that we can run (e.g., `cowsay` or `cowthink`).
Select one with `-e` (required when the package declares no entrypoint):

```bash copy
wasmer run syrusakbary/cowsay -e cowthink -- Hello world
```

If your current directory has a `wasmer.toml` file, you can simply run the local package with:

```bash copy
wasmer run .
```

The `wasmer run` command also allows running from URLs (in case a package is hosted on a different registry).

```bash copy
wasmer run https://wasmer.io/python/python
```


### Run a Wasm file

```bash copy
wasmer run my_program.wasm
```

#### Run a Wasm file with a custom compiler

```bash copy
wasmer run my_program.wasm --singlepass
```

> You can also use `--cranelift` or `--llvm` instead of `--singlepass`.

### Run a WASI or WASIX Module

You can pass arguments to the WASI program:

```bash copy
wasmer run my_wasi_program.wasm -- arg1 arg2 arg3
```

You can also pass environment variables:

```bash copy
wasmer run my_wasi_program.wasm --env MYVAR=MYVALUE -- arg1 arg2 arg3
```

### File access and networking

The guest cannot see your filesystem or network unless you grant access:

```bash copy
wasmer run my_wasi_program.wasm --volume /host/data:/data
```

`--volume HOST_DIR:GUEST_DIR` is repeatable, one flag per mapping.

Guest ports are virtual: a server that logs `Listening on :3000` is not
reachable on host port 3000 by itself. Run with `--net` to enable full
networking and forward ports to the host:

```bash copy
wasmer run my_server.wasm --net
```

`--net` accepts filters, for example `--net "dns:allow=example.com:80"`.
If the program only needs outbound HTTP requests, prefer the narrower
`--http-client`.

<Callout type="warning">
The flags `--dir`, `--mapdir`, and `--command-name` were removed in
wasmer 7.x. Use `--volume` for directory access and `-e` to select a
command.
</Callout>

### Profiling WebAssembly Code

You can enable profiling data generation for your WebAssembly code using the `--profiler` option:

```bash copy
wasmer run my_program.wasm --profiler=perfmap
```

This generates profiling information in the [perfmap format](https://github.com/torvalds/linux/blob/master/tools/perf/Documentation/jit-interface.txt), which can be used with Linux perf tools to analyze the performance of your WebAssembly code. The profiler data is written to `/tmp/perf-{PID}.map`.

This option is available for the Cranelift, LLVM, and Singlepass compiler backends.
