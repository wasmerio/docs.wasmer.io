# Wasmer Runners

A runner defines how Wasmer executes the commands in a package.
The Wasmer runtime supports the following runner:

- [WASIX](/runtime/wasix) (including plain WASI)

[WCGI](/runtime/runners/wcgi) packages use the same packaging workflow, and run on [Wasmer Edge](/edge).

Runner metadata belongs to the package, so the same WASI(X) command can run
through the CLI, the [JavaScript SDK](/runtime/js), or the
[Python SDK](/runtime/python).
